## Utterance / input

Any diagram with a locally added 2D node that has not been saved to the API.

## Steps

1. Draw a diagram and switch to 2D.
2. Add a node, leaving the new node selected.
3. Switch to 3D.

## Expected

The selected local node shows its local summary without requesting server-only explanation data, or
the UI asks the user to save before requesting an explanation.

## Actual

The side panel immediately posts `/v1/explain` for the unsaved node. The API's stored OSG does not
contain that node, so it returns 404 and Chromium emits a console error.

## Evidence

The automatic `browserProblems` fixture caught the console error in the 50-node performance setup.
The retained Playwright trace records a 404 response from `POST /v1/explain` for the unsaved node.

## Resolution

Fixed in `14c2ef7` (`fix(canvas): defer explanations for unsaved nodes`). The automatic
browser-problem monitor now passes on every browser test, including the 50-node setup. Status:
**closed**.
