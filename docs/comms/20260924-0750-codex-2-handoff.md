## What changed

- Replaced the toolbar's 2D and Export placeholders with the shared 2D/3D switch and PNG, SVG,
  GLB, and JSON export controls.
- Added the React Flow editor with grid snapping, minimap, fit controls, editable labels, node add
  and delete, edge connect/reconnect/delete, and keyboard undo/redo/delete.
- Every mutation is applied to a cloned OSG and parsed by `OSGSchema` before the session store is
  changed. The 3D view reads the same updated OSG.
- Added a 100-step bounded snapshot history, save/share clients, and reload restoration using only
  the last explicitly saved OSG id in local storage.

## How to use it

- Select **2D** in the existing diagram toolbar. Edit labels in place, drag nodes, or drag between
  handles to connect/relink. `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, `Ctrl/Cmd+Y`, and `Delete` work when
  focus is not in a text field.
- **Save** sends the validated document to `PUT /v1/osg/:id`. **Share** saves first, then calls the
  API's canonical `POST /v1/share/:id` route and copies the read-only link when Clipboard API access
  is available.
- Global PNG/SVG/GLB/JSON buttons download the current shared OSG in either view mode.

## Known limitations

- The API's published route is `/v1/share/:id` (PROMPT.md section 11), although the assignment's
  shorthand said `/v1/share`; the client follows the implemented canonical route.
- The GLB uses positioned box meshes carrying node labels, not the renderer's React-only primitive
  components. It is a valid glTF 2.0 binary representation of the edited OSG.
